# M83 HI data reduction, step by step

A beginner's guide to reducing MeerKAT HI data of the galaxy M83 (observation 1575768670, 8 December 2019), explained with the plots from a real reduction in CASA 6.7.2.

Read it online: https://parthadeka.github.io/m83-hi-reduction-guide/

The site is built by GitHub Pages with the [Just the Docs](https://github.com/just-the-docs/just-the-docs) theme. Pages are in `index.md`, `observation.md`, `glossary.md` and `steps/`; plots are in `assets/plots/`.
